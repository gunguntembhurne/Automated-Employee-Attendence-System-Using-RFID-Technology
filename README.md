# Automated Employee Attendance System Using RFID Technology

## Project Description
An automated employee attendance system using an LPC2129 ARM7 microcontroller and RFID technology. The system identifies employees using RFID cards and records their attendance. UART is used for RFID communication, I2C is used for the RTC module, and an LCD displays employee information, date, and time.

## Technologies Used
- LPC2129 ARM7 Microcontroller
- RFID
- UART Protocol
- I2C Protocol
- RTC Module
- LCD Display
- Embedded C

## Features
- RFID-based employee identification
- Automatic attendance recording
- Date and time using RTC
- Employee information displayed on LCD
- Duplicate attendance prevention
